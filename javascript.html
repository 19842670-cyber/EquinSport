JavaScript

JavaScript es un lenguaje de programación utilizado para agregar interactividad y funciones a las páginas web.

01

¿Qué es?

JavaScript permite que una página web responda a las acciones del usuario. Por ejemplo, botones, formularios, animaciones, menús y mensajes.

02

¿Para qué sirve?

Sirve para crear sitios más dinámicos e interactivos. También puede modificar elementos HTML y CSS sin tener que recargar la página.
