JSON

JSON significa JavaScript Object Notation y es un formato utilizado para almacenar e intercambiar información.

01

¿Qué es JSON?

JSON organiza la información mediante objetos y propiedades. Es muy utilizado para enviar información entre páginas y servidores.

02

Ejemplo

{
  "producto": "Montura",
  "precio": 350,
  "categoria": "Caballo"
}
